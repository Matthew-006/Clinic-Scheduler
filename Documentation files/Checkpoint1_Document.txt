Data Structures
---------------
1) LinkedQueue (Hassan)
   Events + waiting emergency patients
   Why: FIFO. enqueue/dequeue O(1), removeById O(n)

2) PriorityQueue - sorted linked list (Matthew)
   Waiting regular patients
   Priority = checkInTime + numTests (smaller first)
   enqueue O(n), dequeue O(1)

3) Array inside Branch / SimulationEngine (Kerolos)
   Doctors and branches
   Why: fixed count after load, access O(1)

4) LinkedList (Mohamed)
   Done patients + all patients registry
   insertEnd O(1), findById O(n)

In-visit: Doctor has Patient* currentPatient (no separate list).
